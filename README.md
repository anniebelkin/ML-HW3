# ML-HW3

## Goal
This homework is based on Chapter 11 (multi-layer neural network implemented from first principles) from *Machine Learning with PyTorch and Scikit-Learn* (Raschka et al., 2022).

Requirements covered:
- Extend the original Chapter 11 reference code from **one hidden layer** to **two hidden layers**.
- Train/evaluate on **MNIST** using a **Train (70%) / Test (30%)** split.
- Report predictive performance via **macro AUC** (multi-class OVR) and compare:
  1) manual **1-hidden-layer** baseline,
  2) manual **2-hidden-layer** version,
  3) a framework implementation (**Keras/TensorFlow**).
